# Bennett's Engineering — Debtors Application Form (Version 2)

Version 2 of the Bennett's Engineering debtor application form, supplied by David
(July 2026, "Code review and form setup").

This is a design-tool component export (`.dc.html` files with a `support.js` runtime),
not a React/Next.js codebase. The original React implementation lives at
[bennetts_debtors_form](https://github.com/Sublime1975/bennetts_debtors_form).

## Contents

- `Debtors Application.dc.html` — the full application wizard (welcome, steps, signing)
- `*.dc.html` — individual field components (AddressField, BankNameField, CheckboxField, FileDropzone, ForeignBankField, FormField, SelectField, SignaturePad, ToggleField)
- `support.js` — runtime required by the `.dc.html` components
- `public/logo.png`, `logo.png` — Bennett's Engineering logo
- `screenshots/` — reference screenshots
